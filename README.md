# Hearth

Ambient scenes for the Google TV Streamer: a 4K fireplace, a window where the birds heard today land on a branch, the bird board, live weather, and seasonal scenes — with Spotify playing in the background.

- `web/` — the scene engine the TV app shows (hosted on GitHub Pages)
- `android/` — the small Google TV app that hosts it
- `tools/` — media helpers run by GitHub Actions
